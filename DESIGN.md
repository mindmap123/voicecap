# Design Direction

## Register

Brand landing page.

## Mood

Sharp, operational, premium, and grounded. The page should feel like a serious business system, not a futuristic AI toy.

## Color Strategy

Restrained neutral base with one confident signal accent.

- Background: near-black green-tinted neutral.
- Surface: dark graphite with subtle green tint.
- Text: warm off-white.
- Muted text: gray-green.
- Accent: electric lime for call states and CTAs.
- Secondary accent: amber for missed-call warnings.

Use color for meaning:

- Lime: recovered, booked, active.
- Amber: missed, urgent, revenue leak.
- Neutral: structure and explanation.

## Typography

Use system fonts for MVP speed and performance. Big, tight hero type. Smaller dense operational UI labels in panels.

## Layout

Mobile first. Full-bleed hero. Avoid generic card grids. Use bands, timelines, tables, and operational panels. Cards only for repeated use cases or FAQ items.

## Components

- Header.
- Hero with call-flow visual.
- Problem band.
- Workflow section.
- Use cases.
- ROI calculator.
- Offer section.
- FAQ.
- Lead capture CTA.
- Footer.

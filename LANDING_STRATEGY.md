# Landing Strategy

## Primary Conversion

Request a missed-call audit.

Form fields:

- Name.
- Business type.
- Phone or email.
- Estimated calls per week.
- Main problem: missed calls, booking, qualification, follow-up, after-hours.

## Page Narrative

1. Hero: introduce "le standard anti-perte" and make the cost of silence visible.
2. Demo: one concrete proof module combining voice sample, call transcript, agent role, and SMS output.
3. System: answer, qualify, act, trace.
4. Sector scenarios: artisan, cabinet, real estate, coaching/training.
5. ROI + offer: calculate leakage, then show audit / pilot / system.
6. FAQ + final audit CTA.

## Visual Thesis

A precise, high-contrast operational landing page with a cinematic call-flow visual: phone signal, transcript fragments, lead status, and booked appointment moving through one system.

## Interaction Thesis

- Hero entrance shows missed calls converting into qualified appointments.
- Sticky ROI calculator gives immediate feedback as the user changes values.
- One proof module shows the voice, transcript, agent and SMS output in a single place.

## Copy Rules

- Use French.
- Use concrete business language.
- Avoid generic AI hype.
- Keep CTAs action-oriented: "Calculer mes appels perdus", "Demander l'audit", "Voir le scénario".
